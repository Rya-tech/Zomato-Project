Restaurant Review Sentiment Analysis

An intelligent machine learning project that analyzes customer reviews and identifies whether their experience is Positive, Negative or Neutral. Using Zomato restaurant reviews and restaurant metadata, the system helps understand customer opinions and satisfaction.

Analyze a Review

About The Project

Understanding customer opinions through machine learning.

Customer Reviews

The first dataset contains 10,000 customer reviews, ratings, reviewer information and review dates.

Restaurant Metadata

The second dataset contains 105 restaurant records, including restaurant names, cuisine types, costs, collections and opening timings.

Machine Learning

Both datasets are merged using restaurant names. TF-IDF and Logistic Regression are used to classify customer reviews into sentiment categories.

How It Works

The process followed by our machine learning model.

01. Data Collection

Collect restaurant reviews and restaurant metadata.

02. Data Processing

Merge datasets, clean missing values and prepare sentiment labels from ratings.

03. Model Training

Convert text using TF-IDF and train a Logistic Regression classifier.

04. Prediction

Predict whether a new customer review is Positive, Negative or Neutral.
